# D&V Placas NFC — site

Site de uma página da D&V Placas NFC (https://dvplacasnfc.pt), alojado no GitHub Pages.

- `index.html`: página, estilos e scripts (sem passo de build)
- `privacidade.html`: política de privacidade
- `config.js`: número de WhatsApp e chave pública do Supabase
- `CNAME`: domínio próprio

O formulário de orçamento chama a função `enviar_pedido` no Supabase (projeto D&V PLACAS NFC). Os pedidos aparecem no Radar D&V como contactos "Pedido do site".
